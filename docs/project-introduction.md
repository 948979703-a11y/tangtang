# 新东方 K12 招生平台：引流与蓄养项目介绍

## 一、 项目背景与目标

在新东方 K12 教育业务中，如何从复杂的市场环境中低成本、高效维系潜客（引流），并在建立初步联系后，通过高密度的精细化运营提升用户信任度并最终实现付费（蓄养），是实现业务新一轮收入增长的核心引擎。

传统招生中常面临获客链路碎片化、数据难以沉淀、社群运营缺乏强有力抓手以及一线人工跟进成本过高等痛点。因此，本项目的核心策略是打造一套**覆盖“线下/公域拓客 -> 私域社群深扎 -> 高意向转化”全生命周期**的产品矩阵。通过提供赋能于一线教师、同时极其便于 C 端用户裂变操作的工具链，实现降本增效与招生转化的爆发。

**业务目标可以被量化归结为：**
1. **扩大开口池**：利用极其轻量化的工具，大幅降低线下地推获客的线索门槛和收集阻力。
2. **构建高频心智触场**：通过社群打卡、授课等互动玩法培养信任，彻底盘活冰冷的私域流量。
3. **打通全息画像闭环**：积累用户的每一次互动数据，实现后台的数据反哺，赋能销售实现“看人下菜碟”的精准转化。

---

## 二、 项目整体架构（引流+蓄养路径）

本项目坚持“前端极简，中后台极重”的核心理念，利用微信生态无痛承接 C 端流量，用中后台保障 B 端业务运转。

- **【前端引流（Acquisition）】**：聚焦于地推等线下强力获客场景。通过「小表单」产品，将潜在用户快速引流圈层进私域个人微信号及微信群之中。
- **【生态蓄养（Nurturing）】**：针对已入群的用户，提供包含「打卡活动」、「小课堂内容分发」和「线下体验邀请」为主的三步法触点矩阵。将“销售群”彻底重塑为有价值的“伴学群”与“服务群”。
- **【闭环转化（Conversion）】**：以「客户跟进侧边栏」作引擎大脑，聚合此前的全域互动数据生成精准人物画像，一线课程顾问与老师以此为依据进行精准逼单。

## 三、 核心功能模块详细介绍

### 1. 小表单（线下拓客引流利器）
- **核心场景**：招生环节中高频的地推、校园宣讲、试听体验填单等线索收集阶段。
- **产品逻辑**：
  - **B端创建**：教务老师或活动负责人在后台使用组件化表单快速创建特定场景表单模板。
  - **C端填入**：生成唯一绑定追踪识别的表单小程序二维码。地推场景下，极速唤起微信小程序，用户通过一键授权等操作，数秒内完成信息录入并即时提交。
  - **B端反馈**：用户的扫码留资信息无缝、无延迟流转至业务后台公海或私海池中，供业务主管统一调配跟踪。

### 2. 打卡（高频活跃的伴学工具）
- **核心场景**：社群蓄养的核心推手，通过游戏化和从众驱动培养每日社群黏性。
- **产品逻辑**：
  - **B端创建**：老师可在后台建立不同的打卡主题，自由选择【普通图文打卡模式】与【答题闯关模式】，创建完成后直推至目标微信群。
  - **C端签到**：学员每日通过微信小程序快速进入，进行文字、语音或图片形式的打卡（或在线答题），极大降低参与门槛。
  - **B端督学与点评**：在管理后台，老师可汇总监控每日缺勤名单，并可以直接看到每位学员打卡的详情，进行语音或文字形式的指导点评，打造极致的辅导体验护城河。

### 3. 小课堂（社群干货种草机）
- **核心场景**：社群蓄养的中单环节，通过高质量短、平、快的轻型课程快速建立新东方名师的“专业信任背书”。
- **产品逻辑**：
  - **B端建立**：老师通过系统搭建单场视频录播课或者快捷直播课堂。
  - **C端承接**：生成活动化链接卡片一键落群，用户无需下载独立的沉重 App，直接进入微信 H5 页面即可参与观看互动，实现轻量破局沉浸式转化。

### 4. 体验课（O2O高意向洗粉漏斗）
- **核心场景**：深度蓄养和锁定意向的核心突破口，邀约家长学生亲赴校区“探店”。
- **产品逻辑**：
  - **B端排班**：老师在系统统筹设置线下体验课程主题与容纳名额，一键分发。
  - **C端报名**：通过轻量化流程报名并获取参与资格。
  - **线下履约闭环**：到了排课时段，用户线下到对应校区出示码签到，老师核销即视为上课完成，建立 O2O “线上了解 - 线下落地”强关系链。

### 5. 客户跟进侧边栏（全息作战雷达）
- **核心场景**：销售管理与深度蓄养转化的终端“临门一脚”，服务于一线企微单聊场景。
- **产品逻辑**：
  - **业务融合**：工具高度耦合在企业微信聊天侧边栏，作为随手可用的资料库和客户雷达。
  - **360° 全息视图**：不仅包含学员的**基本信息**与**档案信息**维度，后台系统强关联出涵盖其是否填过表单、最近一次打卡成绩、看了多久小课堂直播、线下体验课履约状态的**画像信息**和**历史报名明细**。
  - **价值释放**：直接拉平新销售与老销售的信息差，助力沟通时能迅速找到“破冰点”并精准定位用户价格带敏感点，推动购买决策。

## 五、 项目价值与后续规划

### 业务沉淀与长期价值
K12 招生引流与蓄养平台的正式落地，不仅宣告了“手工账+盲人摸象”式获客时代的落幕，更成功将分散在冰山下的每一次用户潜客交互均数字化、实体化。产品提供的四大工具体系不仅极大减轻了一线营销及学管团队的操作负担，还成功构建起一个可被量化、可被拆解的高黏性私域护城河模型。

### 下一阶段进阶规划 (Next Roadmap)
1. **AI 智能化打卡批分**：引入大模型与智能 OCR 及语音能力，辅导系统自动针对高频错漏批改“打卡答题”，大幅解放老师日常重复精力占用。
2. **体验课营销链路拓宽**：将体验课分发功能与分步营销卡券体系挂钩（如：上完课即发500元首单满减券），提升连带报名冲动。
3. **基于画像数据的智能推荐**：依据「客户跟进侧边栏」产生的跟进履历与系统画像，建设后台销售跟进的“Sop引擎（Standard Operating Procedure）”，实现“什么时候发、发给谁、发什么推荐话术”的完全自动化指引赋能。
