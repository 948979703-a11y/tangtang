# 招生运营平台 - 打卡活动模块调研报告

基于对新东方招生运营平台（`https://op.xdf.cn/marketing#/revenue/clockIn`）“打卡”功能模块的深度分析，总结以下功能清单、页面结构、交互方式及样式规范。

## 1. 功能清单

*   **活动管理（主列表页）**
    *   **数据概览**：活动数量、参与总数、打卡完成率、人均打卡等核心业务数据的统计看板。
    *   **多维度筛选**：支持根据活动名称/ID搜索，以及状态、机构等下拉框复合查询。
    *   **列表展示**：记录活动基本信息（ID、名称、所属机构、状态等级及人员打卡进度），并提供快速入口（查看/编辑、数据、推广）。
*   **活动创建/编辑（多步表单）**
    *   **分步导航**：基本信息配置 -> 活动内容配置 -> 营销转化配置。
    *   **基本信息**：标题、所属机构、封面上传、打卡日期（支持跳过周末设置）。
    *   **权限限制**：支持所有人参与或通过导入白名单限制指定学员参与。
*   **多维数据分析（隐藏功能/入口）**
    *   支持打卡明细统计，包含每日打卡统计、学员排行、拉新/分发数据监控等功能。
*   **渠道推广**
    *   支持为打卡活动生成专属链接、太阳码/二维码等方式供营销推广使用。
*   **核心特性**：系统支持 Tab 式多任务并发，可同时保留列表和新建页面。

---

## 2. 页面结构与排版

*   **常规布局框架 (Admin Layout)**：
    *   **左侧侧边栏 (Sidebar)**：深色主题 (`#001529`)，承载主要业务线菜单项，支持展开收起。
    *   **顶部导航栏 (Header)**：固定在顶部，提供跨大平台切换功能及用户信息、帮助文档入口。
    *   **标签页导航 (Tabs)**：类似于浏览器的标签页，支持快速切回之前的任务视图而不丢失状态。
    *   **右下侧主体内容区 (Main Content)**：承载实际的数据列表、表单，带灰色背景 (`#f0f2f5`) 作为底色突显内容卡片。
*   **新建活动页面**：
    *   左侧为主操作区（表单配置）。
    *   右侧为固定尺寸的手机模拟器视图（实时预览版面）。

---

## 3. 关键交互方式与体验设计

*   **WYSIWYG 实时预览**：表单数据变更时，右侧手机预览组件即时反馈（如输入标题则手机顶栏立刻变化），极大地提升了容错率。
*   **无缝 Tab 切换**：点击“新建活动”不会发生页面重载跳转，而是产生一个新 Tab，用户返回“活动列表”时仍保留原有的筛选条件。
*   **数据可视与对比**：顶部看板数据不仅给出了绝对值总量，还附加了以 `较昨日` 为基准的环比升降图标（红绿颜色提示）。
*   **多步骤解耦设计 (Stepper)**：业务逻辑链路较长，设计上将其划分为 3 个具体小步骤，缓解配置焦虑的同时保证配置流程不会遗漏逻辑。

---

## 4. 视觉层规范

*   **主色调**：青色/蓝绿色为主的品牌色 `Primary: #00b2a9`。
*   **背景规范**：平台背景灰 `#f0f2f5`，列表/卡内块纯白 `#ffffff`，用阴影 `shadow-sm` 及圆角以形成层级。
*   **文字层级**：使用标准的字号层级，正文一般为 `14px` (`text-sm`)，辅助说明 `12px`(`text-xs`)，重要数据放设为粗体大号 (`24px` / `text-2xl`)。
*   **组件体系**：标准的 Ant Design 风格交互，按钮圆角控制在 `4px - 6px`。

## 5. 原型落地与交付物说明

已在工作目录即刻生成还原静态页面原型文件以供走查评估。
* **文件路径**: `prototype/clock-in.html`
* **技术栈**: 纯 `HTML5` + `Tailwind CSS (CDN)` + `Vanilla JavaScript` (实现 Tab 切换及基本预览绑定)。
* **适用场景**: 可直接用浏览器双击打开浏览完整视觉效果，无需任何 npm/build 配置。
