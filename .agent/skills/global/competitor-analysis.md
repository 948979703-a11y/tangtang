# 竞品分析 (Competitor Analysis) Skill

这个 Skill 将指导你进行标准化、高效的竞品剖析，最终生成一份完善的 SWOT 分析报告。

## 任务步骤

1. **确认竞品名称和核心功能**
   - 引导用户明确要分析的核心竞品名称。
   - 确定此次分析聚焦的核心方向、业务分支或特定功能模块。

2. **多维度信息收集**
   - **产品定位**：分析竞品在市场中的核心占位、Slogan 及其品牌调性。
   - **目标用户**：研究其面向的核心用户画像与切入点。
   - **核心功能**：体验主打业务功能与用户交互闭环。
   - **定价模式**：拆解商业收入模式、会员体系设计、阶梯式订阅定价等策略。
   - **用户评价**：获取应用市场评价、社区反馈及核心舆情。

3. **整理成 SWOT 表格**
   分别从以下维度对竞品与自身情况进行映射，并汇总为易读的 Markdown 表格：
   - **S (Strengths - 优势)**：领先点与护城河。
   - **W (Weaknesses - 劣势)**：目前的体验痛点、业务短板或技术债务。
   - **O (Opportunities - 机会)**：宏观趋势、新风口或可抢先满足的蓝海需求。
   - **T (Threats - 威胁)**：政策变更、新入局者引发的风险等。

4. **输出结论与建议**
   - 基于 SWOT 分析矩阵，得出竞品的综合优劣结论。
   - 为后续的产品迭代与攻防策略提出实质性落地建议与 Action Items。
