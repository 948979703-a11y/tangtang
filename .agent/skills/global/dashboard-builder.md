# 数据看板 (Dashboard Builder) Skill

本 Skill 可以辅助产品经理跳过繁杂的前端业务选型，直接利用 React 组件化和 ECharts 数据底座跑通高颜值的数据实时监控看板演示代码。

## 任务步骤

1. **确认需要展示的指标和图表类型**
   - 沟通需要展现在数据看盘上的直接指标组合（如：当日访问折线、销售额柱状对比、来源占比饼图、流量转化漏斗图等）。
   - 为不同的展示诉求匹配并敲定数据展示的最优可视化图表形态。

2. **生成 React 组件并使用 ECharts 渲染图表**
   - 分拆 Dashboard 首屏结构，构建 React JSX 代码底座方案。
   - 引用 `echarts` 或对应 React 库进行图表的实例挂载与参数（Option 项）注入。
   - 配置一套 Mock API 作为前端图表渲染的数据来源支持，使得前端可以真正“跑”起来查看效果。

3. **确保响应式布局**
   - 运用 CSS Flex/Grid 逻辑赋予页面响应特性，或者依靠 AntD/MUI 此类 UI 中的分栏和响应式格网方案。
   - 务必保证窗口发生调整时，ECharts 画布可完美触发自身内部 Resize，防止变形拥挤。

4. **提供数据更新示例**
   - 加入定时器或特定的状态改变函数 (如按钮 Trigger)，演示数据对象（State）从后端轮询获取或更新时，React 内部状态驱动图表如何动态平滑更新渲染。
