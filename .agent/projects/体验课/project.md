# 项目：体验课

## 项目简介
管理学员参加试听/体验课全流程的移动端工具，包括预约、到场记录、课后跟进等环节。

## 技术栈
- **框架**：React + Vite
- **样式**：Tailwind CSS v3
- **路由**：React Router v6

## 代码路径
