# 老带新活动模块 PRD (v1.0)

## 1. 项目概览
老带新（Referral）通过老学员转介绍新生，参与专属活动获取奖励。

## 2. 核心功能需求

### 2.1 极简视觉设计
- **海报为主**：活动展示以 **16:9** 的海报图片为主体。
- **信息精简**：移除所有非核心字段（截止时间、进度条、文字标题等）。
- **同步标签**：图片下方展示该活动所属学段（如“推荐小学新生”）。

### 2.2 动态学段标签显示逻辑 (Dynamic Tabs)
- **按需展示**：Tab 栏（小学、初中、高中）根据 `ACTIVITIES` 数据动态计算。
- **逻辑细则**：
  - 如果只有一个学段有活动 $\rightarrow$ 不展示 Tab 栏。
  - 如果有多个学段有活动 $\rightarrow$ 只展示有数据的对应 Tab。
- **默认选中**：自动选中第一个有活动数据的学段。

### 2.3 交互说明
- **Header**: 移除分享按钮。
- **引导条**: 在列表上方固定文案：“选择适合好友孩子的学段活动，推荐成功可获得专属福利。”
- **操作**: 点击“立即参与”按钮进行交互。

## 3. UI 规范
- **主题色**: 浅青色 (#2DD4BF)
- **圆角**: 2xl (16px)
- **学段配色**:
  - 小学: 橙色
  - 初中: 青色
  - 高中: 靛蓝色
