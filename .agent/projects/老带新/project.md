# 项目：老带新

## 项目简介
教培机构学员"老带新"活动管理模块，用于跟进老学员推荐新学员的绑定、报名及奖励发放情况。

## 技术栈
- **框架**：React + Vite
- **样式**：Tailwind CSS v3
- **路由**：React Router v6

## 代码路径
```
frontend/src/pages/Referral/
```
