# 项目：打卡项目

## 项目简介
学员学习打卡与作业提交管理工具，帮助老师追踪学生学习坚持情况，支持打卡记录查看与激励反馈。

## 技术栈
- **框架**：React + Vite
- **样式**：Tailwind CSS v3
- **路由**：React Router v6

## 代码路径
```
frontend/src/pages/CheckIn/
```
