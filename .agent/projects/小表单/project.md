# 项目：小表单

## 项目简介
轻量化的信息采集表单工具，用于线下活动现场或微信链接分发，快速收集学员/家长基础信息。

## 技术栈
- **框架**：React + Vite
- **样式**：Tailwind CSS v3
- **路由**：React Router v6

## 代码路径
```
frontend/src/pages/SmallForm/
```
