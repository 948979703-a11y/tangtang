# 项目：客户跟进（学员跟进页面）

## 项目简介
面向教培机构销售/跟进老师，用于在线管理学员信息、查看学员画像、跟进活动记录的移动端 H5 工具页面。

## 技术栈
- **框架**：React + Vite
- **样式**：Tailwind CSS v3
- **路由**：React Router v6
- **图标**：FontAwesome 6
