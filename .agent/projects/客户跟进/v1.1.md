# 客户跟进 v1.1 — 新增分层测模块

## 版本说明
在 v1.0 基础上，在"画像"Tab 中新增**分层测**业务模块，同步迁移为 React 组件化架构。

## 发布时间
2026-03-24

## 本版本变更点
### 新增
- **分层测统计卡片**：位于画像 Tab 顶部，展示"推荐班型"（志高/精进/好学）及最新评测科目与成绩
- **分层测明细折叠列表**：手风琴式展开，每条记录包含：
  - 入学年份（如 2027秋季）
  - 评测时间（如 2026.6.1）
  - 年级（如 八年级）
  - 科目（如 数学）
  - 成绩（如 92分）
  - 推荐班型（如 志高）
  - 评测报告链接

### 移除
- 分层测明细中的"新增评测"按钮（业务上不需要在此处新增）
- 分层测统计区的"共 N 次"数量展示（老师关注的是最新结果而非次数）

### 数据说明
- 推荐班型枚举值：**好学 / 精进 / 志高**
