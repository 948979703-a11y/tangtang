# 客户跟进 v1.0 — 基础底座

## 版本说明
根据提供的 18 张设计截图进行 1:1 还原的交互原型，作为整个项目的初始基准版本。

## 发布时间
2026-03-23

## 核心功能
- 学员基本信息展示（姓名、手机号、标签、描述）
- 画像 Tab：联系人、薄弱科目、科目成绩、考级考证、辅导经历、需求目标、报班偏好
- 上方统计看板：活跃商机、添加员工数据卡片
- 活动信息：老带新统计、到店明细（手风琴折叠展开）
- 全套底部弹窗（编辑学员、手机号、联系人等）

## 代码路径
```
frontend/src/pages/CustomerFollowUp/v1_0/Index.jsx
```

## 备注
此版本为 React 重构前的 HTML 静态原型对应版本（原 `prototype/客户跟进/index_v1.0.html`，已删除，代码已迁移至 React 组件）。
